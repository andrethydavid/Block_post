# 🛢️ Proyecto de Ingeniería de Datos

Proyecto enfocado en construir un flujo de datos completo, desde el entendimiento del negocio hasta la validación y transformación de la información.

## 🎯 Objetivo

Diseñar un proceso de datos confiable, automatizado y reproducible, aplicando buenas prácticas de Ingeniería de Datos.

## 🔄 Flujo del proyecto

1. **Verificación del negocio**

   * Entender los procesos y necesidades del negocio.
   * Identificar las fuentes de información.
   * Definir qué datos se necesitan y para qué serán utilizados.

2. **Extracción de datos**

   * Obtener información desde diferentes fuentes.
   * Preparar los datos para su procesamiento.

3. **Proceso ETL**

   * **Extract:** extracción de información.
   * **Transform:** limpieza, transformación y estructuración.
   * **Load:** carga de los datos procesados.

4. **Validación con Python 🐍**

   * Verificar calidad e integridad de los datos.
   * Detectar valores nulos, duplicados e inconsistencias.
   * Automatizar validaciones y controles de calidad.

5. **Almacenamiento y organización**

   * Estructurar los datos para facilitar su consulta y análisis.
   * Aplicar buenas prácticas de modelado y gestión de datos.

6. **Resultado final**

   * Generar un conjunto de datos confiable y preparado para análisis, BI o modelos de Machine Learning.

## 🧰 Tecnologías
